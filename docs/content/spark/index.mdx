---

Legend Spark is an experimental desktop framework that gives React Native apps native windows, menus, dialogs, and files on the Mac. Use Spark Runner with Fast Refresh, add an app-specific development build when you need native changes, and build a standalone `.app` with embedded JavaScript.

The public package is `@legendapp/spark`. Screens use React Native's renderer and JavaScript runs in Hermes; Node runs the development tooling. Expo Desktop generates the native host, and Expo CLI runs the development session.

Spark is not ready for production. macOS 14+ on Apple Silicon is the primary target. [Get started with the npm package](/spark/getting-started).

Build desktop apps with React Native screens, native windows, menus, dialogs, and files. Edit JavaScript with Fast Refresh.

Install `@legendapp/spark` for the APIs and `spark` CLI. Import features from paths such as `@legendapp/spark/files`.

- **[React Native](https://github.com/facebook/react-native)** renders native interfaces. Application JavaScript runs in Hermes.
- **[Expo](https://github.com/expo/expo)** supplies mobile/web tooling and selected library backends.
- **[Expo Desktop](https://github.com/shirakaba/expo-desktop)** creates projects and generates native desktop hosts.
- **[Legend Spark](/spark)** supplies desktop APIs, native compatibility checks, runtime selection, and build/packaging orchestration. Expo CLI owns Metro and the development terminal.

Node 24.19.0+ runs the tooling. Use npm, pnpm, Yarn, or Bun to manage dependencies. Neither Node nor Bun runs inside the app.

## Three runtime choices

| Runtime | Native contents | JavaScript |
| --- | --- | --- |
| Spark Runner | Shared SDK development profile | Metro / Fast Refresh |
| Custom development build | SDK plus app-specific native dependencies/configuration | Metro / Fast Refresh |
| Standalone macOS application | Production-selected native modules | Embedded bundle |

Start with a compatible Runner. Adding native dependencies, helper executables, or native configuration can require a custom build. Compatibility checks include SDK, architecture, and native signatures. JavaScript-only changes do not require rebuilding.

## Platform scope

| Target | Available workflow | Limits |
| --- | --- | --- |
| macOS 14+, Apple Silicon | Runner, custom development, standalone builds and packaging | Primary target |
| macOS 14+, Intel x64 | Architecture selection across builds, Runner registration/downloads and packaging | Native builds and runtime behavior still need validation; published Runner is ARM64 only |
| Windows 11, x64/ARM64 | Local Runner and custom development builds | Native builds and runtime behavior still need validation; no production packaging or hosted Windows Runner |
| iOS / Android / web | Expo workflows and selected shared API/UI adapters | Desktop APIs do not imply mobile/web support |
| Linux / Mac App Store | Outside the supported workflow | No support claim |

Spark 0.0.1 targets Expo SDK 54, React Native 0.81, and Expo Desktop `1.0.0`. See [status and limitations](/spark/limitations) for platform and feature restrictions.

## Application architecture

For Electron migrations, replace DOM/CSS screens with React Native screens and browser/main-process integrations with supported capabilities. Spark has no Electron compatibility layer. An optional [WebView](/spark/integrations) can host selected web content.

[Helper processes](/spark/integrations) run app-supplied executables. Independent background Hermes heaps use `@react-native-runtimes/core` directly; they remain inside the app process and end when it quits.

A macOS demo for browsing local Codex and Claude transcripts in a virtualized conversation view. Its composer simulates responses locally.

<Callout title="Demo">
  [Download Legend Chat History from GitHub releases](https://github.com/LegendApp/legend-apps/releases). Choose `-arm.zip` for Apple silicon or `-x86.zip` for Intel Macs.
</Callout>

## Built for

- Local transcripts
- Virtualized conversations
- Simulated composer

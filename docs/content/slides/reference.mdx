## Syntax at a glance

| Intent | Write |
| --- | --- |
| New slide | A top-level `---`. |
| Reveal a block | `A thought. {step=1}` |
| Reveal a list | `{steps}` on its own line before the list. |
| Hide later | `A thought. {step=1 until=3}` |
| Match a title | `# The idea {shared=title}` on both slides. |
| Group blocks | `:::group{gap=24}` … `:::`. |
| Private notes | `<!-- 1: Your opening cue. -->` |
| Style text | `## Title {class="text-cyan-300"}` |

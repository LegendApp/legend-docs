From the Legend Apps repository root, install dependencies with `bun install`. Start Metro and run the app in separate terminals:

```sh
bun run hello-world start macos
```

```sh
bun run hello-world run macos
```

The default Metro port is `19097`. The macOS bundle ID is `so.legend.helloworld.macos`.

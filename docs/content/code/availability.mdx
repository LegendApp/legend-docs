<Callout title="Download">
  [Download Legend Code from GitHub releases](https://github.com/LegendApp/legend-apps/releases).
</Callout>

Legend Code requires macOS 14 or later and supports Apple silicon and Intel Macs.

Choose the Legend Code `-arm.zip` archive for Apple silicon or `-x86.zip` for Intel Macs. Unzip it and move the app to Applications. Release builds support automatic updates through Sparkle.

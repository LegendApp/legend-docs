A native code editor for macOS that opens and edits any UTF-8 text file. Save your changes, find and replace text, and work with incremental syntax highlighting and virtualized rendering for large files.

<Callout title="Download">
  [Download Legend Code from GitHub releases](https://github.com/LegendApp/legend-apps/releases). Choose `-arm.zip` for Apple silicon or `-x86.zip` for Intel Macs.
</Callout>

## Built for

- Any text file, including dotfiles and extensionless files
- Save, Save As, undo, and redo
- Find and replace, line editing, and automatic bracket and quote pairs
- Syntax highlighting with language selection and appearance settings

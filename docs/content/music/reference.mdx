Legend Music scans library folders and plays `.mp3`, `.wav`, `.m4a`, `.aac`, `.flac`, `.aif`, `.aiff`, `.aifc`, and `.caf` files. Create, rename, delete, import, export, and edit local `.m3u` playlists. The queue and playback state are restored across launches.

Settings control the current-song overlay’s position and display duration, and a configurable global hotkey can show the main window. Default shortcuts are `Space` or the media play/pause key for playback, `Alt+S` for shuffle, `Alt+R` to cycle repeat modes, `J` for playlist search, and `L` to show or hide the library.

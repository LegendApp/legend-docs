Legend Markdown opens `.md`, `.markdown`, `.mdown`, `.mkd`, and `.mdx` files and creates untitled documents. Save, Save As, and optional autosave write directly to your files. Recent documents are built in, and files reload after external changes when there are no unsaved edits. The app prompts before discarding unsaved work.

The formatting toolbar can appear above selections, at the top, at the bottom, or be hidden. Default shortcuts are `Cmd+Alt+T` to toggle the toolbar, `Alt+Up` / `Alt+Down` to move blocks, and `Cmd+Up` / `Cmd+Down` to focus the first or last block.

User theme files load from `themes/display` and `themes/layout` in the app’s storage directory.

A native macOS home for reviewing repositories, files, patches, and pull requests. Clear diffs, quick navigation, and tools for resolving conflicts.

<Callout title="Preview">
  [Download Legend Diff from GitHub releases](https://github.com/LegendApp/legend-apps/releases). Choose `-arm.zip` for Apple silicon or `-x86.zip` for Intel Macs.
</Callout>

## Built for

- Git + GitHub comparisons
- Unified + block views
- Merge conflict resolution

Open a Git folder, two files, `.diff` or `.patch` files, or GitHub pull-request and commit URLs through dialogs, drag and drop, paste, launch arguments, or the `legend-diff://` URL scheme. GitHub URL loading requires network access. Settings can install an `ldiff` command for opening Git diff arguments in the installed app.

Unified view is the default. Use `Cmd+1` for Unified, `Cmd+2` for Side-by-Side, and `Cmd+[` / `Cmd+]` to navigate to the previous or next changed hunk.

<Callout title="Download">
  [Download Legend Diff from GitHub releases](https://github.com/LegendApp/legend-apps/releases).
</Callout>

The app is currently focused on macOS. Legend Diff requires macOS 14 or later and supports Apple silicon and Intel Macs. Local repository comparisons require Git.

Choose the Legend Diff `-arm.zip` archive for Apple silicon or `-x86.zip` for Intel Macs. Unzip it and move the app to Applications. Release builds support automatic updates through Sparkle.

## Hero prompt

Use case: stylized-concept. Asset type: wide hero artwork for the Legend software family website. Make a sophisticated tactile 3D sculptural interpretation of the white continuous rounded L-shaped loop in the supplied Legend logo. Preserve the distinctive loop path and shape of the white mark, but render the mark as a thick satin silver and translucent ice-blue extruded sculpture, viewed from a gentle oblique angle. Set it on an almost-black charcoal studio background (#0c0d0f), with restrained electric cyan edge lighting and soft realistic shadows. Composition: very wide landscape, sculpture entirely in the right half with breathing room; left half quiet nearly black negative space for HTML headline overlay. Editorial industrial-design photography, precise craftsmanship, subtle surface texture, crisp bevels. No text, no UI, no additional icons, no stars, no purple, no rainbow, no excessive glow. The blue rounded square of the source icon should NOT appear, only the loop sculpture. Save a production-quality wide hero asset.
